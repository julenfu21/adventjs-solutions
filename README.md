## 📖 Overview

[**AdventJS**](https://adventjs.dev/) is a collection of programming challenges created by **@midudev** (links in the [🙏 Acknowledgements](#-acknowledgements) section) and inspired by [**Advent of Code**](https://adventofcode.com/), which can be solved with <img src="assets/javascript-logo.png" alt="JavaScript" width="20" style="vertical-align: middle;"> **JavaScript**, <img src="assets/typescript-logo.png" alt="TypeScript" width="20" style="vertical-align: middle;"> **TypeScript** and <img src="assets/python-logo.png" alt="Python" width="20" style="vertical-align: middle;"> **Python**. It comprises 25 Christmas-themed coding challenges, released **daily from December 1st to December 25th**.

This repository contains **my solutions** to the **AdventJS** challenges, which currently cover the **2025** edition only. Additionally, it allows you to:

- **Get an overview of the challenges**, including **difficulty**, **score** obtained, links to **details** and **total score**.
- **Explore each challenge individually** with access to **🎯 Instructions**, **💡 Examples**, and links to **implementations**, without leaving the repository.
- **Review each solution**, **test them** following the instructions provided in the **🧪 Tests** section and **gain additional insights** through the **🧠 Code Review** section.
- **Navigate** the repository in all supported languages: **English**, **Spanish** and **Basque**.
