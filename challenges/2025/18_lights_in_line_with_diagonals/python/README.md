## 🧪 Tests

Run all tests:

```bash
pytest test_solution.py
```

Run a specific test function:

```bash
# <test_function> = {test_has_four_in_a_row_returns_boolean, test_has_four_in_a_row}

pytest test_solution.py::<test_function>
```

```bash
# <index> = {2 - 6}

pytest test_solution.py::test_has_four_in_a_row[test-<index>]
```
